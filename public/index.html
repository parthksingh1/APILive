    Before you start

    apilive checks keys by calling each provider's API from your computer.

    • Only check keys you own or are authorized to use. Testing anyone else's keys may be illegal.
    • Keys stay on this computer. They're never stored, and never sent to the apilive maintainers.
    • Checks use free endpoints, but each provider sets its own pricing and limits.
