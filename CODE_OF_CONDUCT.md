# Code of Conduct

## Our pledge

We want participation in apilive to be a harassment-free experience for everyone, whatever their age, body size, disability, ethnicity, sex characteristics, gender identity and expression, level of experience, education, socio-economic status, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Expected behaviour

- Be respectful and assume good intent.
- Give and accept constructive feedback gracefully.
- Focus on what is best for the project and its users.

## Unacceptable behaviour

- Harassment, insults, or personal or political attacks.
- Sexualised language or imagery.
- Publishing other people's private information, **including API keys or credentials**, without explicit permission.
- Asking for help using apilive to check keys you are not authorized to use.

## Enforcement

Maintainers may remove, edit or reject comments, commits, issues and other contributions that break this Code of Conduct, and may temporarily or permanently ban contributors who do. Report problems privately to the maintainers through GitHub, using the contact options on the repository or the private reporting described in [SECURITY.md](SECURITY.md).
